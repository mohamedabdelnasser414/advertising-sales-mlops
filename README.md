# Advertising Sales MLOps Pipeline

This project builds a Machine Learning pipeline using GitHub Actions.

The use case is to predict product sales based on advertising spending across TV, Radio, and Newspaper channels.

The project will include:

- Data preprocessing
- Model training and testing
- Flask API deployment
- Docker containerisation
- GitHub Actions CI/CD workflows
- Deployment to Google VM or Kind Kubernetes

## Dataset

The dataset used is `Advertising And Sales.csv`.

Input features:

- TV
- Radio
- Newspaper

Target variable:

- Sales

## Planned MLOps Pipeline

1. Data acquisition and preprocessing
2. Model training and testing
3. Model serving using Flask API
4. Docker image build
5. Continuous Integration using GitHub Actions
6. Continuous Deployment to Google VM or Kubernetes
7. Optional continuous training / monitoring
